What it does

Built for the upload, not the edit

Finish your video in any editor. Cadence handles the part after export: checking it, sending it, and posting it when your audience is awake.

Validate

Schedule

Pick a date and time

A queue shows every post as pending, uploading, processing, published or failed. Edit, cancel or retry from one place.

Drafts

No re-encoding by default.When a file meets TikTok's limits, Cadence uploads the exact bytes you exported.

Fingerprinted at approval.Cadence records the file's SHA-256 when you press Post or Schedule, and refuses to send it if the file changes afterwards.

You decide on any conversion.If TikTok would reject a file, Cadence explains why and asks first. Container fixes are lossless; re-encoding is labelled as reducing quality.

Plain about TikTok's side.TikTok processes every upload for playback. Cadence makes sure it starts from your best file.

Official API only

What TikTok allows, stated plainly

Cadence signs in through TikTok's Login Kit and posts through the Content Posting API. It never scrapes, automates a browser or uses private endpoints, so a few things work differently from the TikTok app.

Scheduling runs on your computer

TikTok's API has no scheduling option, so Cadence sends each post at its time. Keep Cadence open or in the system tray.

In-app TikTok drafts aren't visible

No app can read drafts saved inside TikTok. Use Cadence's draft library, or send videos to your TikTok inbox.

Daily limits apply

TikTok caps how often an account can post through apps in a day. Cadence spaces requests and tells you when a cap is reached.

Your password stays with TikTok

You sign in on TikTok's own page. Cadence keeps only the access token, in your operating system's keychain.

Get started

Runs on Windows, macOS and Linux

Cadence needs Python 3.10 or newer and FFmpeg. Install, add your TikTok developer key, and run.

# install
pip install -r requirements.txt
# add TIKTOK_CLIENT_KEY to .env, then start
python -m cadence
